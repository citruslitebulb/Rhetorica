## 3. Release signing (keystore)

Gradle is already wired. It will sign a release build if these environment variables are set; otherwise release falls back to the **debug** key (fine locally, not for Play).

| Variable | Meaning |
|----------|---------|
| `RHETORICA_STORE_FILE` | Path to the `.jks` / `.keystore` file |
| `RHETORICA_STORE_PASSWORD` | Keystore password |
| `RHETORICA_KEY_ALIAS` | Key alias |
| `RHETORICA_KEY_PASSWORD` | Key password |

- [ ] Generate an upload keystore and store it **outside this repo** (never commit it).
- [ ] Enroll in **Play App Signing** and upload the first AAB.
- [ ] Back up the keystore + passwords somewhere durable (password manager, not chat).
- [ ] Set the four env vars and produce a signed AAB:

```powershell
$env:RHETORICA_STORE_FILE = "C:\path\to\rhetorica-upload.jks"
$env:RHETORICA_STORE_PASSWORD = "…"
$env:RHETORICA_KEY_ALIAS = "upload"
$env:RHETORICA_KEY_PASSWORD = "…"
.\gradlew bundleRelease
```

The AAB lands at `app/build/outputs/bundle/release/app-release.aab`.
